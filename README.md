# DeskHop ERP

ระบบ ERP สำหรับบริหารธุรกิจ **DeskHop**: แอปจองโต๊ะทำงานรายชั่วโมงในคาเฟ่และ co-working space ทั่วกรุงเทพฯ

ไม่ต้องติดตั้งอะไรเพิ่ม ใช้แค่ Python 3.9+ (standard library: `http.server` + `sqlite3`) กับ HTML/JS ล้วน

## วิธีรัน

```bash
python3 app.py --seed          # เปิดที่ http://127.0.0.1:8000 พร้อมข้อมูลตัวอย่าง
python3 app.py --port 9000 --db mydata.db
python3 -m unittest discover -s tests -v   # รันชุดทดสอบ
```

## ระบบที่ 2: ร้านเฟอร์นิเจอร์ไม้สัก (`/teak.html`)

| โมดูล | ทำอะไร |
|---|---|
| **แดชบอร์ด** | ยอดขายที่ส่งมอบ, กำไรขั้นต้น, ออเดอร์ที่กำลังดำเนินการ, ใบเสนอราคา, ลูกหนี้ค้างชำระ, รับเงินเดือนนี้, มูลค่าคงคลัง, ยอดสั่งซื้อ 6 เดือน, สินค้าขายดี, สินค้า/วัตถุดิบใกล้หมด, ออเดอร์เลยกำหนด |
| **ออเดอร์ขาย** | หลายรายการต่อออเดอร์, ส่วนลด, ค่าขนส่ง, ใบเสนอราคา → ยืนยัน → กำลังผลิต → พร้อมส่ง → ส่งมอบ (ตัดสต็อก, ถ้าสต็อกไม่พอจะไม่ยอมให้ส่งมอบ) |
| **รับชำระเงิน** | มัดจำ / ชำระส่วนที่เหลือ / ชำระเต็ม / คืนเงิน และแสดงยอดค้างของแต่ละออเดอร์ |
| **ผลิต / โรงงาน** | ใบสั่งผลิต (ผูกกับออเดอร์ได้), เบิกวัตถุดิบตัดสต็อก, ติดตามขั้นตอน ตัดไม้ → ประกอบ → ขัด/ทำสี → เสร็จ, ผลิตเสร็จแล้วเพิ่มสต็อกและคำนวณต้นทุนสินค้า (วัตถุดิบ + ค่าแรง) |
| **สินค้า / สต็อก** | SKU, หมวด, เกรดไม้ (A/B/C/ไม้เก่า), การทำผิว, ขนาด, ราคา, ต้นทุน, % กำไร, เตือนเมื่อใกล้หมด |
| **วัตถุดิบ & รับซื้อ** | ไม้สักแปรรูป (ลบ.ฟุต), น้ำมัน, อุปกรณ์; รับซื้อแล้วเพิ่มสต็อกและคิดต้นทุนแบบถัวเฉลี่ย |
| **ลูกค้า / ผู้ขาย** | ประเภทลูกค้า (ทั่วไป/ขายส่ง/โรงแรม/ดีไซเนอร์/ออนไลน์), ยอดซื้อรวม, ยอดค้างชำระ; ซัพพลายเออร์และยอดซื้อ |

API อยู่ใต้ `/api/teak/{products|materials|purchases|suppliers|customers|orders|payments|production}` และ `/api/teak/dashboard`

## REST API

`GET/POST /api/{venues|desks|customers|bookings|issues|verifications}`
`GET/PUT/DELETE /api/{resource}/{id}`
`GET /api/dashboard` · `GET /api/meta` · `GET /api/venues/{id}/availability?date=YYYY-MM-DD&start_time=HH:MM&hours=N`

## Deploy บน Render

1. เข้า https://dashboard.render.com → **New** → **Blueprint** → เลือก repo นี้ (Render จะอ่าน `render.yaml` ให้เอง)
   หรือ **New → Web Service** แล้วตั้งค่าเอง: Runtime `Python 3`, Build Command `echo ok`, Start Command `python3 app.py --seed`
2. กด Deploy แล้วเปิด URL `https://<ชื่อ-service>.onrender.com`

แอปจะอ่าน `PORT` ที่ Render กำหนดให้และรับการเชื่อมต่อที่ `0.0.0.0` อัตโนมัติ

> ⚠️ แพ็กเกจฟรีของ Render ไม่มีดิสก์ถาวร ไฟล์ SQLite จะถูกล้างทุกครั้งที่ redeploy หรือ service หลับแล้วตื่น (ข้อมูลตัวอย่างจะถูกโหลดกลับมาใหม่จาก `--seed`)
> ถ้าต้องการเก็บข้อมูลถาวร ให้ใช้แพ็กเกจที่เพิ่ม **Persistent Disk** ได้ เช่น mount ที่ `/var/data` แล้วตั้ง env `DB_PATH=/var/data/deskhop.db`
