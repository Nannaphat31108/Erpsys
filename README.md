# DeskHop ERP

ระบบ ERP สำหรับบริหารธุรกิจ **DeskHop**: แอปจองโต๊ะทำงานรายชั่วโมงในคาเฟ่และ co-working space ทั่วกรุงเทพฯ

ไม่ต้องติดตั้งอะไรเพิ่ม ใช้แค่ Python 3.9+ (standard library: `http.server` + `sqlite3`) กับ HTML/JS ล้วน

## วิธีรัน

```bash
python3 app.py --seed          # เปิดที่ http://127.0.0.1:8000 พร้อมข้อมูลตัวอย่าง
python3 app.py --port 9000 --db mydata.db
python3 -m unittest discover -s tests -v   # รันชุดทดสอบ
```

## โมดูล

| โมดูล | ทำอะไร |
|---|---|
| **แดชบอร์ด** | GMV, รายได้ค่าคอมมิชชัน, ต้นทุนโปรโมชัน, การจองวันนี้, อัตราลูกค้ากลับมาซ้ำ, สถานที่ Verified, อัตราตอบรีวิว, คะแนนเฉลี่ย, % โต๊ะไม่พร้อม |
| **การจอง** | จองโต๊ะ ตรวจเวลาทับซ้อนอัตโนมัติ คิดราคา + โปร "2 ชั่วโมงแรกฟรี" สำหรับการจองครั้งแรก เปลี่ยนสถานะ เช็กอิน / เสร็จสิ้น / ยกเลิก |
| **สถานที่พาร์ทเนอร์** | ราคา/ชม., ยอดซื้อขั้นต่ำที่ร้านคาดหวัง → แสดง *ค่าใช้จ่ายจริงต่อชั่วโมง*, Wi-fi, ระดับเสียง, ระยะเดินจาก BTS, ค่าคอมมิชชัน, พนักงานรู้จักระบบหรือไม่ |
| **โต๊ะ** | โซน (เงียบ/ปกติ/ห้องโทรศัพท์), มีปลั๊กไฟ, สถานะ |
| **ลูกค้า (CRM)** | ข้อมูลติดต่อ (โทร/LINE/อีเมล), ช่องทางที่รู้จัก, จำนวนการจอง, ยอดใช้จ่ายรวม |
| **รีวิวและข้อร้องเรียน** | หมวดปัญหา (wi-fi, เสียง, รูปไม่ตรง, โต๊ะไม่พร้อม, พนักงานไม่รู้ระบบ, ค่าใช้จ่ายแฝง), การตอบกลับ และติดตามสถานะ |
| **ตรวจสอบสถานที่ (Verified)** | บันทึกการตรวจ Wi-fi/เสียง/รูป/บรีฟพนักงาน → อัปเดตข้อมูลสถานที่และให้ป้าย Verified 30 วัน |
| **การเงิน** | ยอดจองต่อสถานที่ รายได้ DeskHop และยอดโอนให้ร้าน |

## REST API

`GET/POST /api/{venues|desks|customers|bookings|issues|verifications}`
`GET/PUT/DELETE /api/{resource}/{id}`
`GET /api/dashboard` · `GET /api/meta` · `GET /api/venues/{id}/availability?date=YYYY-MM-DD&start_time=HH:MM&hours=N`
